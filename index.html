⚙️ Настройка облачной синхронизации

Для синхронизации между устройствами нужен бесплатный проект Firebase.

  1. Перейдите на console.firebase.google.com
  2. Создайте проект (или используйте существующий)
  3. В разделе Realtime Database создайте БД в режиме "Тест"
  4. Скопируйте конфигурацию из Настроек проекта

Конфигурация сохраняется только в вашем браузере.
